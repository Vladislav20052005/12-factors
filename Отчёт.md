Это приложение для встраивания рекламы в сайт

Написано на:
frontend: html/css/javascript
backend: golang
БД: postgreSQL
веб-сервер: nginx
развертывание: docker-compose

Сущности:
Пользователь
Медиафайл
Рекламное объявление (медиафайл + ссылка на ресурс)

1. Все приложение находится в одном репозитории
2. Зависимости описана в go.mod, подгружаются на этапе сборки в контейнер
3. Переменные среды лежат в файле .env, код не содержит конфигурацию
4. Сервис БД полностью подключается переменными среды
5. ./Release собирает образ с переменными окружения, ./Run запускает контейнеры
6. Код не хранит состояние, состояние хранится только в БД
7. Приложение открывает обозначенный порт для подключений, веб-сервер проксирует запросы на него, порт указан в .env
8. Все процессы web, процессы создаются при запросе
9. Код компилируется на этапе Build, запускается уже готовый файл. Graceful shutdown сначала дает завершить обработку запросов, затем закрывает подключение к БД. Сервис устойчив к падениям в силу stateless кода
10. -
11. Все запросы и ошибки логируются в stdout
